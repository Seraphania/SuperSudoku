# SuperSudoku Demo Release

Working Sudoku game making use of an API.
Created for TAFE Cert IV Unit ICT40120 - Mobile Development

### Platform
Android API 35+

## Installation
To Install on an android device, tap "Releases":  
<img width="304" height="108" alt="image" src="https://github.com/user-attachments/assets/1ba9eec2-92bd-4246-9c42-a074ce5eca44" />

Select the latest release and tap the *.apk file:  
<img width="1187" height="49" alt="image" src="https://github.com/user-attachments/assets/424be728-c3b8-4ba9-910c-6f5709a1326a" />


Once the file has downloaded to your device it can be installed with pacakge installer. 
Your device will scan the file before installation, and ask if you wish to continue.

**Note:**  
Because this package is for demonstration and testing purposes, it still contains a "instant solve" button. 
This is also left in because the chosen API does not provide puzzles with a unique solution, meaning that a sudoku may be completed correctly, but will not register as correct because it doesn't match the API solution. 

It is recommended to play only medium and hard puzzles at this stage.

A future release will include full validation of completed puzzles, for now, please make use of the 'Debug Solve' button.
